숲 횡스크롤 맵 — 3600 × 540 px

파일과 합성 순서 (아래에서 위)
1. paper_background.png : 흰 종이 바탕과 옅은 16px 모눈
2. background.png       : 구름과 먼 산. 하늘은 종이가 보이도록 투명
3. midground.png        : 뒤쪽 숲, 집, 울타리, 유적 장식
4. terrain.png          : 바닥, 그루터기, 통나무, 돌턱, 언덕
5. foreground.png       : 가장 앞의 검은 가지, 잎, 풀
6. preview.png          : 위 다섯 레이어를 같은 좌표에서 합성한 결과

모든 파일은 3600 × 540이며, 좌측 상단 (0, 0)에 겹칩니다.
배경 장식은 midground, 실제 이동 지형은 terrain에 들어 있습니다.
terrain 및 foreground의 빈 영역은 알파 투명입니다.
기본 이동 기준은 위에서 y=396, 캐릭터 높이 기준은 80px입니다.
언덕에서는 발 위치가 지형 높이에 따라 달라집니다.
이미지에는 캐릭터, 적, 탄환, UI, 좌표 안내선을 포함하지 않았습니다.

배치 흐름
집과 그루터기 → 완만한 첫 언덕 → 통나무와 열린 길 → 돌턱 →
두 번째 높은 언덕 → 내려오는 길과 통나무 → 숲의 빈터.
전경 식물은 시작과 끝뿐 아니라 중간 구간에도 배치되어 있습니다.

게임 적용
각 레이어를 원본 크기로 같은 좌표에 배치하세요.
PNG는 그림 자산입니다. 충돌 판정 및 이동 코드는 포함하지 않습니다.
실제 충돌선은 terrain의 눈에 보이는 윗면에 맞춰 게임에서 설정하세요.
독립적으로 스크롤하는 패럴랙스를 적용하면 화면 구도는 달라질 수 있습니다.

제작
내장 이미지 생성 도구로 승인된 시작 화면을 참고하여 구간별 그림과
투명 레이어를 제작한 뒤, 공통 캔버스에 정렬하여 합성했습니다.
레이어 분리 과정에서 승인 미리보기의 세부 선 일부가 달라졌습니다.

제작 프롬프트 요약
흰 종이 위 흑연 연필 숲, 하늘에만 보이는 옅은 모눈, 원본 크기의
집과 나무, 밝고 넓은 이동 공간, y=396 기본 바닥, 큼직한 그루터기와
통나무 및 두 번의 높은 언덕, 맵 전반에 분산된 어두운 전경 식물.
캐릭터/적/UI/문자 없이 각 레이어의 빈 부분은 투명하게 유지.
