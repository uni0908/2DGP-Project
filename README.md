# Doodle Wars

pico2d로 개발하는 2D 액션 슈팅 게임입니다.

개발 요구사항과 단계별 완료 조건은 [PRD](docs/PRD.md)를 참고하세요.

## 기본 구조

- `main.py`: 게임 실행 시작점
- `game_framework.py`: 장면 전환과 게임 루프
- `scroll_mode.py`: 다섯 레이어 숲 배경과 자동 보스 진입
- `camera.py`: 맵 경계를 지키는 가로 추적 카메라
- `player_actions.py`: 두 화면이 공유하는 낙서·지우개 조작
- `play_mode.py`: 보스전 화면의 입력, 업데이트, 그리기
- `player.py`: 플레이어 이동, 점프, 총격
- `game_world.py`: 지형·플레이어의 레이어별 관리
- `doodle.py`: 고정 낙서 지형
- `eraser.py`: 지우개 투척과 낙서 제거
- `bullet.py`: 플레이어·적의 탄환과 피해 처리
- `enemy.py`: 고정 위치에서 색상별 탄환을 발사하는 패링 테스트 적
- `boss1.py`: 보스1 전용 네 가지 공격과 상태 전환
- `homing_missile.py`: 유도탄 추적·2차원 충돌·패링
- `sweep_laser.py`: 낙서를 보존하며 통과하는 상승·하강 레이저
- `boss.py`: 기존 Boss 이름을 위한 호환 모듈
- `assets/images/`: 게임에서 사용하는 이미지
- `assets/sounds/`: 효과음과 배경음악
- `Slides/`: 기획서와 발표 자료

## 실행과 조작

실행하면 가로 3,600픽셀의 다섯 레이어 숲 배경에서 시작합니다. 주인공 외형 높이는 80픽셀, 평지 발 위치는 y=144입니다. 현재는 배경 구도 확인 단계여서 그림 속 언덕·그루터기·통나무 충돌은 별도로 연결해야 합니다. 일반 적·획득 아이템 배치도 준비 중입니다. 오른쪽 끝에 도달하면 보스1 전투로 자동 전환되고 체력과 낙서·지우개 수량이 이어집니다. 맵의 낙서·탄환은 전환 시 정리합니다.

F1은 맵으로, F2는 보스1 화면으로 바로 이동하는 테스트 단축키입니다. 단축키 전환은 새 상태로 시작합니다. 맵에서 R은 맵을 처음부터, 보스전에서 R은 처치·게임 오버 후 전투를 재시작합니다.

보스전은 전체 전투 모드입니다 (`LASER_TEST_MODE = False`). 첫 공격은 일반 공격이고, 이후 네 패턴을 중복 없이 섞습니다. 레이저만 시험하려면 `play_mode.py`에서 `LASER_TEST_MODE = True`로 바꾸세요.

Python과 pico2d가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
python -m pip install pico2d
python main.py
```

- 왼쪽·오른쪽 방향키: 이동
- 스페이스바: 짧게 누르면 낮은 점프, 길게 누르면 높은 점프
- 공중에서 스페이스바를 떼었다 다시 누르면 0.16초 동안 몸통 패링 활성화 (분홍색 몸통 표시)
- 탄막 공격은 패링 불가. 일반 공격의 분홍·하늘탄은 공중 재입력으로 패링 가능
- 아래 방향키 누르기: 웅크리기 (지상에서 높이 절반, 이동 속도 절반, 점프 불가)
- S: 바라보는 방향 앞에 낙서 생성 (공중에서도 가능, 화면 밖·겹치는 위치는 생성 불가)
- 아래 방향키+S: 발밑에 낙서 생성. 낙하 중 발판을 만들어 착지 가능 (일반 바닥 아래·겹침 위치는 생성 불가, 수량 미소모)
- D: 바라보는 방향으로 지우개 투척 (처음 닿은 낙서 1개 제거 후 낙서 수량 +1로 회수)
- 발판 위·공중에서 아래 방향키 + D: 발밑으로 지우개 투척 (밟은 낙서 제거 후 낙하). 일반 바닥에서는 웅크린 채 앞으로 투척
- A 누르기: 기본 총 연사 (자원 소모 없음)
- 게임 오버 후 R: 재시작
- Escape 또는 창 닫기: 종료

현재 적은 **보스1**이며 **일반 공격으로 시작한 뒤 네 공격의 순서를 매 묶음마다 섞어** 전투합니다. 같은 공격은 연속되지 않으며 각 공격은 회복까지 마친 뒤 전환합니다. 탄막 공격은 0.45초 간격으로 6묶음, 묶음당 6발입니다. 일반 공격은 상하 왕복하며 3발 연사 → 잠시 멈춤 → 패링탄 단독 발사와 여유 시간을 반복합니다. 보스 체력은 30, 플레이어 체력은 5이며 현재 몸 전체에 피해가 들어갑니다. 탄막 공격의 휴식에는 높이가 112→56픽셀로 줄어듭니다. 처치·게임 오버 후 R로 재시작할 수 있습니다.

낙서는 아래에서 통과하고 위에 착지하며, 옆면은 막힙니다. 양쪽 진영의 총알을 막고 20발을 맞으면 파괴됩니다. 발판에서 벗어나거나 밟던 낙서가 삭제·파괴되면 떨어집니다. 지우개는 테스트 적을 지우거나 피해를 주지 않습니다.

탄막 공격은 낙서를 2~3층 높이로 쌓아 방어해보세요. 휴식에는 y=152~232에서 랜덤 상단 사격을 합니다. 아래로 내려와 D로 사격 경로를 열고 낮은 보스에게 반격하세요. 이전 탄은 계속 남으므로 주의하세요. 탄막 공격은 전부 일반탄입니다. 지우개로 제거한 낙서는 1개 회수하고 지우개는 1개 소모합니다.

일반 공격에서는 분홍·하늘탄을 일반탄 묶음과 분리해 단독 발사합니다. 분홍은 낙서 +1, 하늘은 지우개 +1로 보충할 수 있습니다. 패링탄 뒤에는 2.5초 동안 새 일반탄을 쏘지 않습니다. 바닥 쓸기·발판 높이 저격은 아직 기획 후보입니다.

유도탄 공격은 일반 유도탄 2발을 0.7초 간격으로 발사합니다. 기존 적 탄을 모두 낙서 차단·충돌로 해소한 다음 분홍 또는 하늘 유도탄이 단독으로 나옵니다. 색상 유도탄이 해소될 때까지 다른 공격은 없고, 이후 1초 여유를 준 뒤 다음 패턴으로 넘어갑니다. 패링 성공 후 도약은 기존과 같습니다.

유도탄은 시간 경과·화면 밖 이탈로 사라지지 않고 계속 추적합니다. 낙서에 막히거나 플레이어 피격·패링 충돌이 처리되면 소멸합니다. 일반 총알은 기존대로 충돌 또는 화면 이탈 시 사라집니다. 모든 탄은 상태 전환·보스 처치로 강제 삭제하지 않습니다. 공격선·예고 카운트다운은 없으며, 동작 전환 표현은 향후 적 애니메이션 작업에서 보완합니다.

레이저 공격은 두께 16픽셀의 가로 빔이 180픽셀/초로 아래→위→아래 왕복합니다. 낙서는 피해 없이 통과해 그대로 남지만, 플레이어 몸에 닿으면 피격됩니다. 보스는 3초간 기를 모은 뒤 발사하며, 레이저는 패링할 수 없습니다. 왼쪽 끝 48픽셀은 회피 공간입니다.

발판을 지울 시점은 플레이어가 ↓+D로 선택합니다. 하강 레이저가 접근하기 전에 발판을 지워 내려오고, 바닥에서 아래키를 유지해 웅크리세요. 레이저는 웅크린 머리 위에서 멈추고 사라지므로 제자리에서 피할 수 있습니다. 서 있으면 맞습니다. 상승 레이저를 향해 떨어지면 가로질러 맞을 수 있는 점은 그대로예요. 레이저 전용 모드는 유지합니다.

공중 재입력으로 공중제비와 분홍 잔상이 표시되는 동안 색상 탄을 패링하면 분홍은 낙서 +1, 하늘은 지우개 +1을 얻고 섬광과 함께 다시 도약합니다. 실패한 공중 입력만으로는 더블 점프하지 않습니다. 일반탄과 활성 시간이 끝난 뒤의 접촉은 피격됩니다. 계속 누르고 있어도 패링 시간은 갱신되지 않고, 성공 후 연속 패링에는 재입력이 필요합니다. 피격 후 1초 무적은 유지합니다. 판정은 그림의 회전과 무관하게 기존 몸통 주변 범위를 사용합니다.

주인공은 `output/player-sprites-v1/`의 PNG 두 장과 JSON으로 표시합니다. 이동·조준·점프·웅크리기·피격·죽기·패링 동작을 사용하고, 좌우 반전과 총구 좌표를 적용합니다. 연사 중 깜빡임을 줄이기 위해 별도 전신 반동 포즈로 교체하지 않고 사격 애니메이션을 연속 재생합니다. A+위는 수직 사격, A+위+좌우는 이동하며 대각선 사격입니다. 원본과 제작 자료도 같은 폴더에 보관합니다.

낙서·지우개는 각각 10개로 시작하며 사용마다 1개 소모하고, 패링으로 보충할 수 있습니다. 낙서 생성 위치가 유효하지 않으면 소모하지 않고, 지우개는 빗나가도 소모합니다. 지우개로 낙서 제거에 성공하면 낙서 수량이 1개 돌아오며, 총알에 의한 파괴에는 회수되지 않습니다. 화면 위에 남은 수량을 표시합니다. 임시 설정과 검증 결과는 PRD를 참고하세요.

충돌 회귀 테스트는 프로젝트 폴더에서 `..\.venv\Scripts\python.exe -m unittest discover -s tests -v`로 실행합니다.

웅크리면 발 위치를 유지하며 실제 피격 높이도 줄어듭니다. 키를 떼면 일어나지만 머리 위에 낙서가 있으면 공간이 확보될 때까지 웅크립니다. 웅크린 상태에서도 A 사격·S 낙서·D 지우개를 사용할 수 있습니다.

수업 공용 환경은 상위 `2dgame/.venv`의 Python 3.13.7입니다. VS Code에서 `2dgame` 폴더를 열고 기존 `현재 수업 Python 파일 실행` 구성을 사용하거나, 프로젝트 폴더에서 `..\.venv\Scripts\python.exe main.py`로 실행할 수 있습니다.
