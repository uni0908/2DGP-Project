# Doodle Wars

pico2d로 개발하는 2D 액션 슈팅 게임입니다.

개발 요구사항과 단계별 완료 조건은 [PRD](docs/PRD.md)를 참고하세요.

## 기본 구조

- `main.py`: 게임 실행 시작점
- `play_mode.py`: 플레이 화면의 입력, 업데이트, 그리기
- `player.py`: 플레이어 이동, 점프, 총격
- `game_world.py`: 지형·플레이어의 레이어별 관리
- `doodle.py`: 고정 낙서 지형
- `eraser.py`: 지우개 투척과 낙서 제거
- `bullet.py`: 플레이어·적의 탄환과 피해 처리
- `enemy.py`: 고정 위치에서 색상별 탄환을 발사하는 패링 테스트 적
- `boss.py`: 예고·정량 탄막·휴식을 반복하는 1번 보스 패턴
- `assets/images/`: 게임에서 사용하는 이미지
- `assets/sounds/`: 효과음과 배경음악
- `Slides/`: 기획서와 발표 자료

## 실행과 조작

Python과 pico2d가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
python -m pip install pico2d
python main.py
```

- 왼쪽·오른쪽 방향키: 이동
- 스페이스바: 짧게 누르면 낮은 점프, 길게 누르면 높은 점프
- 공중에서 스페이스바를 떼었다 다시 누르면 0.16초 동안 몸통 패링 활성화 (분홍색 몸통 표시)
- 패링 연습: 보스가 쏘는 색상 탄 아래에서 짧게 점프한 뒤, 키를 떼고 다시 누르세요. 첫 점프만으로는 패링되지 않습니다.
- 아래 방향키 누르기: 웅크리기 (지상에서 높이 절반, 이동 속도 절반, 점프 불가)
- S: 바라보는 방향 앞에 낙서 생성 (공중에서도 가능, 화면 밖·겹치는 위치는 생성 불가)
- D: 바라보는 방향으로 지우개 투척 (처음 닿은 낙서 1개 제거)
- 아래 방향키 + D: 발밑으로 지우개 투척 (밟고 있는 낙서를 지워 낙하 가능)
- A 누르기: 기본 총 연사 (자원 소모 없음)
- 게임 오버 후 R: 재시작
- Escape 또는 창 닫기: 종료

현재 6단계의 첫 보스 패턴을 구현했습니다. 오른쪽 보스는 예고 1.2초 → 0.45초 간격으로 6묶음 발사 → 휴식 4초를 반복합니다. 묶음당 일반탄 6발로 총 36발을 쏩니다. 보스 체력은 30, 플레이어 체력은 5이며, 모든 상태에서 현재 보스 몸 전체를 공격할 수 있습니다. 휴식에는 보스가 기를 모으듯 높이가 112→56픽셀로 줄고 실제 피격 범위도 낮아집니다. 처치 또는 게임 오버 후 R로 재시작할 수 있습니다.

낙서는 아래에서 통과하고 위에 착지하며, 옆면은 막힙니다. 양쪽 진영의 총알을 막고 20발을 맞으면 파괴됩니다. 발판에서 벗어나거나 밟던 낙서가 삭제·파괴되면 떨어집니다. 지우개는 테스트 적을 지우거나 피해를 주지 않습니다.

보스 공격은 세로로 넓어서 낙서 한 층만으로 서서 막기 어렵습니다. S와 점프를 조합해 낙서를 2~3층 높이로 쌓아보세요. 휴식에는 새 탄의 발사가 멈추지만 이미 날아오는 탄은 남습니다. 낙서가 내 총알도 막고 보스도 낮아지므로 D로 사격 경로를 치운 뒤 A로 반격하세요. 이번 패턴은 전부 일반탄이므로 패링하거나 자원을 보충할 수 없습니다. 패턴 2~4는 아직 구현하지 않았습니다.

공중 재입력으로 몸통이 분홍색인 동안 색상 탄을 패링하면 분홍은 낙서 +1, 하늘은 지우개 +1을 얻고 다시 도약합니다. 실패한 공중 입력만으로는 더블 점프하지 않습니다. 일반탄과 활성 시간이 끝난 뒤의 접촉은 피격됩니다. 계속 누르고 있어도 패링 시간은 갱신되지 않고, 성공 후 연속 패링에는 재입력이 필요합니다. 피격 후 1초 무적은 유지합니다. 덤블링 애니메이션 없이 몸통 주변에서 판정합니다.

낙서·지우개는 각각 10개로 시작하며 사용마다 1개 소모하고, 패링으로 보충할 수 있습니다. 낙서 생성 위치가 유효하지 않으면 소모하지 않고, 지우개는 빗나가도 소모합니다. 화면 위에 남은 수량을 표시합니다. 임시 설정과 검증 결과는 PRD를 참고하세요.

충돌 회귀 테스트는 프로젝트 폴더에서 `..\.venv\Scripts\python.exe -m unittest discover -s tests -v`로 실행합니다.

웅크리면 발 위치를 유지하며 실제 피격 높이도 줄어듭니다. 키를 떼면 일어나지만 머리 위에 낙서가 있으면 공간이 확보될 때까지 웅크립니다. 웅크린 상태에서도 A 사격·S 낙서·D 지우개를 사용할 수 있습니다.

수업 공용 환경은 상위 `2dgame/.venv`의 Python 3.13.7입니다. VS Code에서 `2dgame` 폴더를 열고 기존 `현재 수업 Python 파일 실행` 구성을 사용하거나, 프로젝트 폴더에서 `..\.venv\Scripts\python.exe main.py`로 실행할 수 있습니다.
